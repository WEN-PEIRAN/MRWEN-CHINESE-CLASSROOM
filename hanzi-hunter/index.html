STUDENT HELP

How to Play Hanzi Hunter

Choose a profile

Select or create a profile with your name and year level.

Set up a game

Choose the player mode, matching mode, year, topic, vocabulary lists and number of words. Two-player games also include a guest and optional turn limit.

Match cards

Match Hanzi with pinyin, English, or both. Correct matches disappear while remaining positions stay fixed.

Two players

Correct matches earn one point. Incorrect matches switch players. Timed turns show a message before switching.

Records and backups

Records are stored in this browser. Export profile JSON before clearing browser data or changing devices.
