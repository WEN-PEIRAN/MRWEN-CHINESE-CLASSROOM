HONGBAO_APP_ONLINE_V3

SETUP
Copy your original complete images folder alongside index.html. Images are not included.
The app automatically fetches ./2026-hongbao-data.json on HTTP/HTTPS, including when hosted inside a portal subfolder. Replace that file and redeploy for updates. No build step required.
Local file:// preview retains the optional JSON picker because automatic local file fetching is restricted. It does not upload data.

V2
Four year tiles; complete year leaderboards; active and inactive students shown identically; balance descending; equal balances share competition rank (1,1,3); name is a stable secondary ordering only; search across years on the home screen or within the selected year; back navigation; equipment and original peak-based level details; Brisbane data timestamp; refresh; read-only.
Cross-year search cards show each student's rank within their own year, not an overall rank.

PRIVACY
This is an openly viewable leaderboard, not an authenticated personal portal. Full names and all JSON records can be downloaded by visitors. Only publish where authorised. Noindex is not access control.
