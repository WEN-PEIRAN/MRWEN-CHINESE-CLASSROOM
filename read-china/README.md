# Read China V1.2

## Open the app
1. Extract the ZIP file.
2. Keep all files together in the same folder.
3. Double-click `index.html`.

The app works locally without internet access and is suitable for GitHub Pages.

## Version 1.2 updates
- Corrected bookshelf alignment with equal book heights and fixed title, metadata and action areas
- Each desktop shelf row now has its own wooden shelf below the books
- Removed decorative book rotation so every book sits level
- Replaced estimated reading time with automatically calculated word or Hanzi character counts
- Expanded all ten English readings for Year 7–10 students
- Expanded the Chinese panda reading to a longer supported text
- Pinyin and English notes remain on by default
