## Chinese Vocabulary Flashcards v1.4

Package name: chinese-vocabulary-flashcards-v1.4

### Version 1.4 update
- Restored the complete vocabulary data from Version 1.2 without removing or replacing any existing topics, lists, or words.
- Added `Version 1.4` beside the footer credit.
- Preserved the Version 1.2 interface, flashcard behaviour, responsive design, images, and icons.

### App features
- Students choose a year level, unit topic, and one or multiple vocabulary lists.
- Vocabulary lists must come from one selected unit topic.
- Topics with no vocabulary lists still appear but are greyed out.
- Flashcards show Hanzi by default.
- Pinyin and English are revealed separately.
- Students can move to previous or next cards, shuffle cards, restart the selected set, or return to setup.

### How to update vocabulary
Open `vocabulary-data.js` and keep the existing structure: years > topics > lists > words.
