HANZI DEFENCE  V1.3
Open index.html in Chrome or Edge (computer only). The game goes fullscreen when you click LAUNCH.
Optional: put a music file named bgm.mp3 in this folder.
Vocabulary: replace vocabulary-data.js with your updated file (same format).
Images are in the img folder (logo + favicon).
Default controls: Up/Down = aim, F or Space = fire, W/S = move turret (after Rail Module), P = pause, Esc = pause.
Change keys in Settings (main menu or pause menu). Settings are saved in this browser.
